# UI Components

## Landing Page
Komponen yang digunakan:
- Logo Homy
- Navbar Menu (Beli, Sewa, KPR, Lainnya)
- Button Daftar/Masuk
- Hero Section
- Headline Utama
- Deskripsi Aplikasi
- CTA Button “Selengkapnya”
- Ilustrasi Rumah Modern
- Background Decorative Shape

Detail tampilan:
- Menggunakan konsep minimalis modern
- Dominasi warna putih, cream, dan biru
- Layout 2 kolom (teks kiri, ilustrasi kanan)
- Navbar berada di atas tanpa sidebar
- Hero image rumah modern sebagai fokus visual utama

## Dashboard (Sesudah Login)
Komponen yang digunakan:
- Top Navbar
- Logo Homy
- Menu Dashboard
- Explore Property
- Favorite
- Messages
- Profile Dropdown
- Notification Icon
- Welcome Header User
- Search Filter Properti
- Input Lokasi
- Dropdown Tipe Properti
- Dropdown Rentang Harga
- Button Cari Sekarang
- Property Card
- Button Simpan
- Button Lihat Detail
- Pagination

Perubahan setelah login:
- Tombol “Daftar/Masuk” berubah menjadi “Profile”
- User dapat mengakses Favorite dan Messages
- Terdapat icon notifikasi
- Dashboard menjadi lebih personal
- Menampilkan nama pengguna pada bagian welcome section

Detail tampilan:
- Menggunakan konsep modern real estate dashboard
- Tidak menggunakan sidebar
- Fokus utama langsung ke listing properti
- Layout responsive dan minimalis
- Menggunakan card properti modern seperti marketplace properti
- Warna dominan putih, biru gradient, dan abu soft
